## 4. 統計方法與假設檢定
* **選用方法**: **Welch's Two-Sample t-test（異質變異數兩樣本 t 檢定）**
* **方法選擇依據**: 
  反應變數（身高）屬於數值型連續變數。根據指導原則，在比較兩組平均數時，預設優先使用 Welch's t-test，而不假設兩組母體變異數相等。本分析透過 Welch's 公式進行自由度修正，以有效防範變異數相異所帶來的統計偏誤。
* **統計假設評估摘要**:
  1. **獨立性 (Independence)**: 通過。數據源自隨機抽樣調查，且男女兩個群體相互排斥，滿足獨立樣本假設。
  2. **測量尺度 (Measurement Scale)**: 通過。反應變數為連續數值，符合 t 檢定要求。
  3. **常態性 (Normality)**: 通過。基於兩組樣本量極大（均遠大於 30），根據中央極限定理 (CLT)，樣本平均數之抽樣分佈趨近於常態分佈。
  4. **變異數同質性 (Variance Homogeneity)**: 不假設相等；直接透過 Welch's 異質變異數修正公式調整自由度進行防範。

在 $\alpha = 0.05$ 的顯著水準下，由於 p-value 極小 ($p < 0.001$)，故拒絕虛無假設。統計結果提供強烈證據顯示，美國男女高中生的平均身高存在高度顯著差異，且在實際脈絡中，男性的平均身高顯著高於女性。
