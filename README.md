## 1. 研究題目與資料集
* **研究題目**: 男女高中生的生理性別與身高關係
* **研究問題**: 男女高中生的平均身高是否存在顯著差異？
* **資料來源**: 美國疾病管制與預防中心 (CDC) 2007 年青少年危險行為調查數據庫 (`YRBS_2007.csv`)。

## 2. 變數定義與分組基準
### 2.1 獨立變數 (分組變數)
* **原始欄位**: `WhatIsYourSex` (資料集代碼 `q2`)
* **清洗後欄位**: `Gender_Label`
* **資料型態**: 類別變數 / 二元變數 (Binary Variable)
* **分組基準**:
  * **女性群組 (Female)**: 樣本數 6,490 筆，作為分析的基礎參照群體 (Baseline Group)。
  * **男性群組 (Male)**: 樣本數 6,572 筆，作為獨立的對照比較群體。
### 2.2 依變數 (反應變數)
* **原始欄位**: `HowTallAreYouWithoutShoesInMeters` (資料集代碼 `q3`)
* **清洗後欄位**: `Height`
* **資料型態**: 連續變數 (Continuous Variable)
* **計量單位**: 公尺 (m)
* **異常值處理**: 僅保留介於 0.5 至 2.5 公尺之間的合理身高。原始問卷中的無效代碼（如 `9.99`）與缺失值（NaN）一律採用完全刪除法 (Listwise Deletion) 予以剔除，防範不完整填報干擾檢定結果。

## 4. 統計方法與假設檢定
* **選用方法**: **Welch's Two-Sample t-test (異質變異數兩樣本 t 檢定)**
* **選用依據**: 依變數（身高）為連續數值，且本分析不假設男女兩群體的母體變異數相等。透過 Welch's 公式進行自由度修正，能有效防範變異數相異所帶來的統計偏誤。
* **統計假設評估**:
  1. **獨立性 (Independence)**: 通過。數據源自隨機抽樣調查，且男女兩個群體相互排斥，滿足獨立樣本假設。
  2. **測量尺度 (Measurement Scale)**: 通過。依變數為連續數值，符合 t 檢定要求。
  3. **常態性 (Normality)**: 通過。兩組樣本量均極大（遠大於 30），根據中央極限定理 (CLT)，樣本平均數之抽樣分佈趨近於常態分佈。
  4. **變異數同質性 (Variance Homogeneity)**: 不假設相等。直接透過 Welch's 公式調整自由度進行修正。

## 5. 核心統計結果與最終推論
| 統計量項目 | 數值 / 結果 | 備註說明 |
| :--- | :---: | :--- |
| **顯著水準 ($\alpha$)** | 0.05 | 虛無假設拒絕閾值 |
| **檢定統計量 ($t$)** | 92.3129 | Welch's t 檢定值 |
| **雙尾機率值 ($p$-value)** | < 0.001 | 精確值為 `1.1373e-302` |
| **點估計平均差距** | 0.1275 m | $\overline{x}_{\text{male}} - \overline{x}_{\text{female}}$ |
| **95% 信賴區間 (CI)** | [0.1248, 0.1302] m | 實際為 12.48 至 13.02 公分 |

### 最終結論
在 $\alpha = 0.05$ 的顯著水準下，由於 p-value 極小 ($p < 0.001$)，故強烈拒絕虛無假設（$H_0: \mu_{\text{male}} = \mu_{\text{female}}$）。
統計結果提供高度顯著的證據顯示，美國男女高中生的平均身高存在高度顯著差異。在實際脈絡中，男性的平均身高（1.7574 m）顯著高於女性的平均身高（1.6299 m），兩組平均差距約為 0.1275 公尺（12.75 公分）。
此外，兩組身高落差的 95% 信賴區間為 **[0.1248, 0.1302] 公尺**（即 12.48 至 13.02 公分）。由於此信賴區間完全不包含 0（且與無差異基準線 `y = 0` 有極大差距），進一步交叉證實了男性高中生在生理身高上顯著高於女性高中生的母體事實。
